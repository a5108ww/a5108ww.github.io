#### 複合型指令（自動化）

git diff 指定索引的檔案：

```powershell
function gd {
    param(
        [Parameter(Mandatory=$true)]
        [int]$index
    )
    $files = git status --porcelain |
        Where-Object { $_ -match '^[ MADRCU?]{1,2}\s+' } |
        ForEach-Object { $_.Substring(3) }

    if ($index -lt 0 -or $index -ge $files.Count) {
        Write-Host "索引超出範圍 (0 ~ $($files.Count - 1))" -ForegroundColor Red
        return
    }

    $target = $files[$index]

    git diff $target
}
```

git add 指定索引的檔案：

```powershell
function ga {
    param(
        [Parameter(Mandatory=$true)]
        [int]$index
    )
    $files = git status --porcelain |
        Where-Object { $_ -match '^[ MARC?]{1,2}\s+' } |
        ForEach-Object { $_.Substring(3) }

    if ($index -lt 0 -or $index -ge $files.Count) {
        Write-Host "索引超出範圍 (0 ~ $($files.Count - 1))" -ForegroundColor Red
        return
    }

    $target = $files[$index]

    Write-Host "git add -> $target" -ForegroundColor Green
    git add $target
}
```

用 VS 開啟資料夾：

```powershell
function open-folder {
    param(
        [Parameter(Mandatory=$true)]
        [string]$repo_name
    )

    $fullPath = $global:MyVsWorkDir + '\' + $repo_name

    if (-Not (Test-Path $repo_name)) {
        Write-Host "資料夾不存在: $fullPath" -ForegroundColor Red
        return
    }

    & $global:VSPath $fullPath
}
```

用 VS 開解決方案：

```powershell
function open-sln {
    param(
        [Parameter(Mandatory=$true)]
        [string]$repo_name
    )

    $fullPath = $global:MyVsWorkDir + '\' + $repo_name

    if (-Not (Test-Path $fullPath)) {
        Write-Host "資料夾不存在: $fullPath" -ForegroundColor Red
        return
    }

    $sln = Get-ChildItem -Path $fullPath -Filter *.sln | Select-Object -First 1

    if ($sln -eq $null) {
        Write-Host "找不到 .sln 檔案於資料夾: $fullPath" -ForegroundColor Red
        return
    }

    & $global:VSPath $sln.FullName
}
```

自定義的 command，參數設定自動補文字（test 跟 oo）：

```powershell
Register-ArgumentCompleter -Native -CommandName open-sln -ScriptBlock {
    param($wordToComplete)

    'test','oo' |
        Where-Object { $_ -like "*$wordToComplete*" } |
        ForEach-Object {
            [System.Management.Automation.CompletionResult]::new(
                $_, $_, 'ParameterValue', $_
            )
        }
}
```

5. 每 5 秒檢查 docker 是否有開啟，有開就啟動特定 container，沒開就繼續等待：

```batch
REM 啟動Docker以及Sql Container
echo Waiting for Docker to start...

goto CHECK

:CHECK
docker info >nul 2>&1

if %errorlevel%==0 (
    goto DO_ACTION
)

echo Docker not ready, retry in 5 seconds...
timeout /t 5 >nul
goto CHECK

:DO_ACTION
echo Docker is ready,Start Local Sql Server Container...

REM start container
docker start mycontainer
```

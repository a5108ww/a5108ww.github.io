## 前言

我們買車了！

所以來確認一下買車後，會有哪些需要定期保養的項目。

## 五油三水

- 五油：引擎機油、自動變速箱油（波箱油）、煞車油、動力方向機油、汽油。
- 三水：水箱冷卻液（水箱水）、電瓶水、雨刷水。

雨刷水不建議加自來水，自來水雜質多、容易結水垢，建議用雨刷精依比例稀釋後再加。

自行檢查：水箱、雨刷水、機油

**保養週期與項目表**

| 保養類型    | 建議週期                                  | 主要項目                                             |
| ----------- | ----------------------------------------- | ---------------------------------------------------- |
| 小保養      | 每 5,000 公里或 6 個月                    | 更換引擎機油、機油濾芯（機油芯）                     |
| 中/定期項目 | 每 10,000 公里或 1 年                     | 檢查/更換冷氣濾網、空氣濾網、電瓶狀況                |
| 大保養      | 每 20,000 至 40,000 公里                  | 更換煞車油、水箱水、變速箱油、火星塞、檢查煞車來令片 |
| 輪胎與皮帶  | 輪胎 40,000 公里 / 4 年；皮帶 70,000 公里 | 輪胎前後對調、檢查胎紋深度與胎壓                     |

## 機油

### 汽車機油 VS 速克達機油

汽車引擎轉速較低，適合黏度較低的機油；汽車專用機油另外添加了節能省油的減摩劑。

速克達引擎轉速較高，且引擎內機油含量較汽車少，所以要用速克達專用機油，它耐高溫、抗剪切。

汽車與速克達機油，因油品耐高溫、抗剪切以及濃稠度因素，不建議交錯使用。

若真的要交錯，汽車機油可以加給速克達；但速克達機油不可加給汽車。

### 機油認證

選擇機油，先看是否有認證。

| 類型   | 認證                                           | 說明                                                                                                      |
| ------ | ---------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| 汽車   | API SP（美國石油協會）                         | S 系列：用於汽油引擎；    C 系列：用於柴油引擎                                                            |
| 汽車   | ILSAC GF-6（國際潤滑油標準化暨認證委員會規範） | 在 API SP 基礎上，要求更高的燃油經濟性、低溫流動性與廢氣催化轉換器保護                                    |
| 速克達 | JASO MB（日本汽車標準組織）                    | 低摩擦                                                                                                    |
| 速克達 | API（美國石油協會）                            | 汽油引擎的清淨與抗磨等級，字母越往後等級越高（例如 SL、SM、SN、SP）。現今多數速克達建議選擇 SN 或 SP 等級 |

### 機油的類型

機油主要是依基礎油（base oil）分類。基礎油大約佔機油的 70–90%，其餘是添加劑。
常聽到的「礦物油、半合成、全合成」，就是依基礎油來分的。

**常見的市售分類**

- 礦物油：由原油直接精煉，價格最便宜。性能足以應付一般使用，但高溫下比較容易氧化變質，低溫流動性也較差。
- 半合成油：礦物油混合部分合成油。混合比例沒有規定，有些只加了少量合成油，所以性能落差很大。
- 全合成油：Group III、IV、V 為主。耐高溫、抗氧化、低溫流動性好，蒸發損耗少，可以撐比較久，價格也最高。

**基礎油的五個等級（API 分類）**

| 等級      | 製程／來源                 | 一般市售名稱                       |
| --------- | -------------------------- | ---------------------------------- |
| Group I   | 原油溶劑精煉，雜質較多     | 礦物油（舊式）                     |
| Group II  | 加氫處理，比較純淨         | 礦物油（現代主流）                 |
| Group III | 深度加氫裂解，性能大幅提升 | 多標示為「全合成」                 |
| Group IV  | PAO（聚α烯烴），化學合成   | 全合成（高階）                     |
| Group V   | 酯類等其他合成油           | 全合成（頂級，多為添加或混合使用） |

**性能比較**

| 項目               | 礦物油 | 半合成 | 全合成 |
| ------------------ | ------ | ------ | ------ |
| 價格               | 低     | 中     | 高     |
| 耐高溫、抗氧化     | 普通   | 中等   | 好     |
| 冷車啟動保護       | 普通   | 中等   | 好     |
| 蒸發損耗（吃機油） | 較多   | 中等   | 較少   |
| 可用里程           | 短     | 中     | 長     |

### 機油番號介紹

{低溫啟動黏度}W-{高溫黏度}

低溫啟動黏度：數字越小表示機油的低溫黏度越低，低溫流動性越好，適用的氣溫越低。

高溫黏度：數字越大表示機油黏度越大，適用的曲軸箱溫度越高，在 100°C 高溫時的黏度保護力較高。

**低溫黏度對照**

| 番號(W) | 易於起動之最低溫(℃) |
| ------- | ------------------- |
| 0       | -35                 |
| 5       | -30                 |
| 10      | -25                 |
| 15      | -20                 |
| 20      | -15                 |


**常見速克達用的複級黏度油品**

| 番號           | 適用情況                                                         |
| -------------- | ---------------------------------------------------------------- |
| 5W-30          | 部分較新的水冷車款會用，偏省油                                   |
| 5W-40          | 和 10W-40 高溫黏度相同，冷車流動性更好，多為全合成               |
| 10W-30         | 也很常見，部分速克達指定這個，比 10W-40 稍稀、稍微省油           |
| 10W-40         | 最常見。大多數台灣速克達的手冊都指定這個，氣冷、水冷都適用       |
| 15W-40、20W-50 | 偏稠，多用於老車、引擎磨耗較大或長時間高負載的情況，現在比較少見 |

**常見汽車用的複級黏度油品**

| 番號          | 適用情況                                         |
| ------------- | ------------------------------------------------ |
| 0W-8、0W-16   | 最新的超低黏度，部分日系油電車和新款省油引擎指定 |
| 0W-20         | 目前日系、韓系車最主流，油電車也多用這個         |
| 5W-30         | 非常普遍，涵蓋許多日系舊款、美系及部分歐系車     |
| 0W-30         | 部分歐系車指定，兼顧冷車流動與高溫保護           |
| 5W-40、0W-40  | 歐系車常見，特別是渦輪、高性能或柴油車           |
| 10W-40        | 多用於老車或高里程車，新車已經很少指定           |
| 15W-40        | 主要是柴油貨車、商用車                           |
| 5W-50、10W-60 | 跑車或賽道用途，一般車用不到                     |

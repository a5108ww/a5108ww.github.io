# 前言

9/10-17，蜜月行程安排，前面 4 天逛京都的景點，第 5 天上午京都最後一個景點逛完就會帶著行李出發神戶。

這篇先記錄第 1～3 天，後面的行程放在下篇。

# 第 1 天（9/10）

台灣時間 08:15 搭乘星宇航空，並於當地時間 11 點多抵達神戶機場，接著搭 Port Liner 前往神戶三宮（Sannomiya）站。

{% include photo.html src="2026_Japan_Travel/day1/day1_landing_to_japan.jpg" caption="降落前從機窗看到的瀨戶內海" %}

中午簡單在神戶三宮站附近的美食街吃個炸豬排飯跟漢堡肉排飯[^lunch1]，偷偷嘴一下，味道挺普通的~

  {% include photo.html src="2026_Japan_Travel/day1/day1_lunch2.jpg" caption="漢堡肉排飯" %}

吃飽飯，前往 **京都河原町站（Kawaramachi）** 的飯店[^hotel1] check in，然後晚上去新京極逛逛，順便在附近吃個拉麵[^dinner1]，出乎意料地好吃，但湯汁有點鹹。

{% include photo.html src="2026_Japan_Travel/day1/day1_market.jpg" caption="寺町京極商店街" %}

> **今日心得**
> 
> 第 1 天也是初次來到日本，發現日本的街道跟台灣比起來乾淨太多。而且日本的車輛，不管是汽車還是機車，遇到該停的路口，一定會停下來再走。
> 
> 中午吃的飯，味道就是美食街的水準，不雷~~
> 
> 晚餐吃的拉麵，雖然很鹹，不過確實讓我很驚艷，是好吃的，大推。
>
> 今日步數：17,989
